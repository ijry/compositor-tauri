# v0.0.1 发布执行计划

> **For agentic workers:** Use executing-plans 在当前修复分支内逐项执行；不创建子代理。完成后勾选对应步骤。

**Goal:** 提交并推送本轮 PSD / RAW 修复，通过现有 CI 发布插件 `0.0.1`。

**Architecture:** 修复分支提交后快进合并到 `main`，推送 `v0.0.1` 标签触发 `release-plugin.yml`。CI 完整构建、测试、校验后发布 GitHub Release，并通过既有 release 环境 PAT 同步插件市场。

**Tech Stack:** Vue 3、TypeScript、pnpm、Playwright、GitHub Actions、GitHub CLI。

**Spec:** 用户明确要求「推送，发布0.0.1版本」；修复范围见 `docs/fixes/production/修复计划.md`。

## 全局约束

- 版本统一为 `0.0.1`，标签为 `v0.0.1`；不覆盖已有同名标签或其他提交的产物。
- 不新增业务行为；保留 PSD 合成导出的限制提示，发布不等于完整生产认证。
- 不提交 `%SystemDrive%/`、构建缓存、密钥或原始 PAT；不修改真实宿主安装目录。
- 使用已有 CI；只有确认 job 成功和市场成功日志后才勾选发布完成。
- 本地包使用 `dist-pack/v0.0.1` 独立目录，不能混入上轮 `0.1.0` 包。
