# 合成器 v0.0.1

Vue 3 组件化的 OTools 图像编辑插件，发布包为 `otools-compositor-0.0.1.oplg`。

## 本版修复

- **PSD 调整效果导出**：含调整层时不再静默丢失画布上的调整效果。先显示兼容性确认，确认后导出包含当前完整可见效果的8/16位合成像素层；无调整层的工程继续分层导出。
- **RAW 滤镜裁剪**：裁剪结果同步图层位置、尺寸和链接蒙版，不再拉伸回旧尺寸。覆盖缩放、旋转、翻转、透视、选区，以及一次撤销/重做。
- 增强取消和过期会话保护：取消保存不触发额外下载；非法裁剪明确报错；源文档变化后拒绝应用旧预览。

## 验证范围

发布流程执行完整306项浏览器回归、14项发布脚本测试、类型检查与构建、ZIP/清单/CRC/SHA256独立校验。具体执行结果见同目录 `0.0.1-validation.json` 和 GitHub Actions。

## 已知限制与使用建议

- 含调整层的 PSD 导出是**用户确认后的可见结果合成**，不是原生可编辑调整层。组、蒙版、隐藏图层及画布外内容不会作为可编辑结构保留在该合成 PSD 中；继续编辑请保存 `.comp` 工程。
- 真实 OTools 原生对话框、Photoshop 和厂商 RAW 样本未完成实机验收；CMYK、32位HDR、CR3/RAF及部分压缩RAW仍有格式限制。
- 本版适合受控试用，不能将自动化测试通过理解为所有功能已完成生产认证。重要工程请保留原文件和备份。

## 安装

下载 Release 资产 `otools-compositor-0.0.1.oplg`，通过 OTools 安装本地插件包。发布包移除 `devUrl` / `quickDev`，不依赖本地开发服务器。
