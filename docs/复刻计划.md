## 说明

- 渲染层为 Canvas 2D 像素合成（上游为 Metal/GPU），大图预览按 1/2、1/4、1/8 降采样以保证流畅。
- 相机 RAW 仅支持 TIFF 容器格式（DNG / CR2 / NEF / ARW / ORF / PEF / SRW / RW2）；CR3 与 RAF 会给出明确提示。
- PSD 导入保留图层、组、蒙版、混合模式与简单横排文字；投影/内投影以外的效果只近似保留或忽略，详见 README「与上游的差异」。
