# 合成器专业版（otools-compositor）

跨平台专业图像编辑器，参考 [robbietilton/Compositor](https://github.com/robbietilton/Compositor) 复刻实现，
以 **Vue 3 + TypeScript 组件化** 的 otools 插件形态交付，Windows / macOS / Linux 通用。

## 当前验证与位深支持

2026-10-09：已修复审计清单中的74项问题，249项浏览器回归和14项发布脚本测试通过。支持8/16位像素与蒙版工作链路、16位PNG/PSD/工程保存及按预算裁剪解码大PSD/PSB。详见 [修复进度](docs/fixes/修复进度.md) 和 [第二批验证范围](docs/fixes/remaining/README.md)。

以上为指定场景的本地验证，不代表真实OTools、Photoshop、厂商RAW及所有格式变体已通过；32位HDR/CMYK等不支持的输入会明确拒绝。显示、JPEG/WebP按格式约定转8位，不改写高精度源数据。

## 开发与构建

```bash
pnpm install
pnpm dev        # 独立开发调试（127.0.0.1:5191）
pnpm typecheck  # vue-tsc 类型检查
pnpm build      # 产出 dist/index.html
```

## 部署到 otools

```powershell
pwsh -File scripts/deploy-to-otools.ps1 -OtoolsRoot D:\Repos\xyito\otools\otools
# 之后在 otools 仓库中：
pnpm --dir plugins/otools-compositor install
pnpm --dir plugins/otools-compositor build
```

插件被放到 `otools/otools/plugins/otools-compositor` 后，`vite.config.ts` 会自动改用 otools 仓库自带的
`createOtoolsPluginSdkViteConfig`，从而获得 quickDev、SDK 别名与依赖兜底能力；独立仓库里则使用等价配置。

## 已实现功能（对应上游 README）

- **图层**：图层与组、不透明度、Photoshop 全套 24 种混合模式（顺序一致）、图层蒙版（可绘制/反相/应用）、
  剪贴蒙版、调整层（12 种）、图层效果（描边/投影/颜色叠加/内阴影/外发光/内发光）、向下合并、合并图层、合并组、
  合并全部、复制、重命名（双击）、上移/下移、编组/取消编组、右键菜单。
- **变换**：非破坏性移动 / 缩放 / 旋转 / 翻转，⌘ 拖拽手柄自由扭曲（单应矩阵）、方向键 1px / 10px 微移、
  自动对齐（参考线 / 网格 / 图层边缘与中心 / 文档边界）。
- **选区**：矩形、椭圆、自由与多边形套索、魔棒（容差 / 连续 / 全图层取样）、对象选择、色彩范围、
  全选 / 取消 / 反选、扩展、收缩、羽化、边界、由图层像素或蒙版建立选区、加选 / 减选 / 交叉。
- **绘画与修复**：画笔（大小 / 硬度 / 不透明度 / 平滑）、橡皮擦、污点修复（补丁搜索）、仿制图章（对齐 / 单层）、
  模糊工具、涂抹、液化（推 / 旋转 / 膨胀）、渐变（线性 / 径向 / 角度 / 对称 / 菱形 + 抖动 + 反向）、
  形状工具（矩形 / 圆角矩形 / 椭圆 / 直线，保持可编辑）、文字工具（多行换行、字距、行距、对齐、加粗/倾斜）、
  吸管与前景/背景色（X 交换、D 复位）。
- **调整与滤镜**：色相/饱和度（含着色）、色阶、曲线、曝光度、渐变映射、颗粒、黑白、色彩平衡、反相、
  高斯模糊、动感模糊、添加杂色（可复现种子）；破坏性滤镜：添加杂色、渐晕、辉光、色调反差、镜头校正、
  移除背景、USM 锐化、降噪、抖动。
- **画布与文件**：多文档标签页、标尺、参考线（可拖拽生成）、网格、Snap To、画布大小（九宫格定位）、
  图像大小、修边、旋转/翻转画布、导入 PNG/JPEG/WebP/BMP/GIF/SVG/TIFF、PSD/PSB（带转换报告）、
  相机 RAW（DNG/CR2/NEF/ARW 等 TIFF 容器解码 + 显影面板）、导出 PNG/JPEG/WebP、导出 PSD、复制合并。
- **工程包**：`.comp` manifest v11 + `images/*.png` 图层与蒙版资源，保存时先生成同级临时完整包，再备份旧包并提交；
  打开中的工程支持约 1/3 秒轮询热重载，重载保留缩放与滚动、清空历史。
- **界面**：顶部菜单、工具栏（分组 + 快捷键角标）、随工具切换的选项头（数值标签可拖拽擦洗）、
  图层面板、属性面板、历史/颜色/信息面板、对话框集合、全套 Photoshop 风格快捷键（含 0-9 输入不透明度）。
- **图层拖拽**：图层面板支持拖拽排序（拖到行上/下边缘插入）、拖到组中部嵌套进组、
  Option(⌥) 拖拽复制、拖到列表空白处移动到根层最底部；拖到收起的组上会自动展开；
  整棵子树随父图层一起移动，并自动做环路检测与历史记录。
- **浮动面板停靠**：属性 / 图层 / 历史面板可停靠在左、右、底部，也可浮动在画布之上；
  浮动面板可拖动标题栏移动、拖右下角缩放、拖到窗口边缘松手即停靠；
  停靠面板可折叠、拖边缘调整厚度，布局会持久化到宿主本地状态。
- **启动页**：没有打开文档时显示欢迎界面，提供新建 / 导入图片 / 打开工程 / 导入 PSD / 导入 RAW 五个入口、
  最近工程列表、三个由代码即时生成的示例工程（渐变与文字、图层组与蒙版、调整层）以及主题切换。
- **快捷键可重映射**：帮助 → 键盘快捷键打开编辑器，点击「录制」后按任意组合键即可改键（Enter 确认、Esc 取消），
  冲突会给出提示，可单项恢复或一键恢复全部，修改结果持久化到宿主本地状态。
- **主题**：暗色 / 亮色 / 跟随系统三档，整体配色由 CSS 变量下发，并与 Element Plus 暗色变量联动；
  混合模式、采样方式等界面文案已中文化（内部仍保留英文标识以兼容 .comp 与 PSD）。

## 与上游的差异（已在 `docs/复刻计划.md` 中标注）

1. 渲染为 Canvas 2D 像素合成（上游为 Metal / GPU），大图预览按 1/2、1/4、1/8 降采样。
3. 相机 RAW 仅支持 TIFF 容器格式（DNG / CR2 / NEF / ARW / ORF / PEF / SRW / RW2）；
   CR3（ISO-BMFF）与 RAF（Fujifilm 私有格式）会给出明确提示而非静默失败。
4. PSD 导入保留图层、组、蒙版、混合模式与简单横排文字元数据；六种基础效果已接入导入/导出；复杂效果、矢量和智能对象需按转换报告及真实样本再验收。

## Review 修复与安全保存（2026-10-08）

- 文字工具：单击创建自动尺寸点文字，默认使用前景色；拖动创建段落框。可在画布输入框直接多行输入，Ctrl/⌘+Enter 或失焦结束编辑，再次点击已有文字继续编辑。顶部参数会同步修改当前文字图层，修改已保存文字也会显示未保存提示。
- 工具头读取当前工具实际参数，画笔等归一化参数显示为百分比；滚动区域继续使用 auto。
- .comp 重开保留组 ID、父引用、剪贴标记、组/调整层蒙版和 warp 信息；资源缺失或层级损坏时拒绝载入，不再静默丢层。warp/clipping 等扩展字段在本插件内保留，不能据此宣称所有上游版本完整兼容。
- 安全保存要求宿主支持 invokeNativeRaw 的 tools_webview_rename_entry。旧宿主不支持时明确拒绝替换，不降级为覆盖写入。
- 保存时选择已存在的空文件夹或有效工程目录；目录检查或备份重命名失败立即终止。
- 生成 `工程目录.saving-<ID>` 完整包后，先将旧包改名为 `工程目录.backup-<ID>` 再提交新包。提交失败会尝试回滚，备份不自动删除，确认新工程正常后可自行清理备份。
- 这不是原版 macOS 的原子目录替换：如果进程在两次重命名之间被强制终止，可将 `.backup-<ID>` 目录恢复为原工程名。备份保证旧文件不被逐个覆盖，不能保证系统断电下所有写入已持久化。

复现回归覆盖文件写入与重命名失败、缺失图片/蒙版、同长度热重载、缓存刷新、尺寸撤销、图层组可见性、投影层级和文字输入。未在真实用户工程上执行故障注入。

## 第二轮 Review 修复（2026-10-08）

- 结构操作保存独立的前后图层快照，涵盖新增、复制、编组、解组、删除和合并；快照像素计入历史内存预算，交错画布操作后仍可撤销重做。
- 菜单与标签关闭共用未保存确认入口；按原文档 ID 关闭，取消或等待期间继续编辑均保留文档。
- 图层面板缺省只操作活动层，切换文档清理旧选择；行菜单绑定目标层，复制组包含全部子孙。
- 历史提交、撤销重做、属性、可见性和重命名统一标记未保存。单纯切换选择或视口不标记内容修改。
- 热重载有未保存确认、内容修订与取消检查；绘画/保存时推迟处理。自身保存刷新监视基线，不清空历史。
- 上游 v11 效果的 RGB 分量、文字对齐/行距/彩色区间、独立蒙版变换通过独立编解码层转换；仍可读取之前插件保存的对应字段。

本轮只修复审查列出的场景，并不表示全部上游字段（例如形状、调整层和显式剪贴源引用）已实现完整互通。原生 macOS 工程写入与真实宿主故障恢复仍需跨平台实机验证。详细进度见 `docs/review二轮修复计划.md`。

## 第三轮 Review：像素操作一致性

- 画布旋转移动图层中心而不重采样原像素；画布大小只调整边界与锚点偏移，不恢复图层原始尺寸。
- 图像大小保留原有图层比例与组/调整层蒙版灰度，独立蒙版和非等比变换同步处理。
- 合并图层不再重复透明度，保持未合并图层顺序；合并组涵盖全部子孙。
- 像素层的蒙版先统一采样到原生像素网格，再变换及处理效果，应用前后不因网格不同跳变；剪贴覆盖包含基础层的蒙版与可见性。
- 蒙版画笔支持黑白灰插值、半透明选区、独立蒙版坐标和组/调整层蒙版；半透明图像笔触按非预乘 RGBA source-over 计算。

详见 `docs/review三轮修复计划.md`。本轮验证的是列出的复现场景，不声明所有上游行为完全一致；非等比旋转图层可能使用插件的四点变换扩展字段。

## 第四轮 Review：编辑目标、剪贴板与透明度

- 复制/粘贴采用独立的像素或图层快照；普通复制读取活动层，复制合并读取可见合成，选区复制保留裁剪位置与灰度覆盖。
- 填充、清除、模糊通过统一编辑目标映射图像或蒙版网格；清除图像仅降低 alpha，不重复缩暗 RGB。
- 区域模糊使用正确的局部索引与 halo，滤波时处理预乘颜色、写回时恢复非预乘 RGBA，避免透明洞与染色边缘。
- 混合模式采用 W3C 源覆盖公式；剪贴栈共享基础 alpha，普通组仍保持上游通过式行为。
- 蒙版目标下，尚未实现蒙版算法的污点修复、仿制、涂抹和液化工具明确拒绝操作，不再意外修改原图。画笔、橡皮擦、模糊以及填充/清除支持蒙版。

详细进度见 `docs/review四轮修复计划.md`。本轮仅保证所列回归场景，不声明所有上游行为或工程扩展字段均完全兼容。

## 第五轮 Review：选区、历史与层级顺序

- 破坏性滤镜先计算完整结果，再按投影到目标网格的选区混合；空选区不执行、不标记修改，灰度覆盖只应用一次。
- 图像/蒙版反相统一检查目标与选区，保留 alpha，记录撤销重做和未保存状态；蒙版开关和剪贴等标量属性按文档、图层 ID 回放历史。
- 图层面板、画布合成和移动操作共用层级遍历；组与子孙作为整块移动，折叠仅影响面板显示。
- 选区生成蒙版以及加载蒙版为选区按实际变换采样；生成操作消耗选区，并在一次撤销中恢复蒙版和选区。

本轮新增 30 项回归，详细进度见 `docs/review五轮修复计划.md`。仍以列出的场景为验证范围，之前明确声明的上游兼容和功能限制没有被视为已完成。
